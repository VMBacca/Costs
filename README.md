## Learning Objectives

Personal learning project focused on:
- State management and business logic
- Understanding the syntax and practical usage of React components, hooks, props, and methods
- Modeling simple real-world scenarios such as project lifecycle and budget tracking

---

## Features

- Create and list projects
- Assign project lifecycle stages (planning, design, development)
- Track and update project budgets over time
- Multi-page layout using routing
- Styled with CSS3

> ⚠️ **Note:** This project is not responsive and was developed for learning purposes only.
